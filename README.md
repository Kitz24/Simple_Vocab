# Simple Vocab

Store and Revise newly discovered English words and Improve your Vocabulary.

---

## Features

* In-app dictionary to search word meanings and usage examples using a Dictionary API.
* Word search and save functionality for maintaining personalized vocabulary lists.
* Random word feature to support spaced repetition and improve memorization.
* Offline access using local storage with synchronization to the backend when online.

---

## Tech Stack

* Frontend: Flutter
* Local Storage: Hive (Flutter)
* APIs: Dictionary API

---

## App Overview

The application focuses on improving vocabulary retention by combining quick dictionary lookups, personalized word lists, and randomized revision for better memory recall. All user data is stored locally using Hive, enabling fast access and offline usage without relying on a remote backend.

## How to Run the Project

### Prerequisites

* Flutter SDK installed
* Android Studio or VS Code
* Android Emulator or physical Android device

### Steps

1. Clone or download the repository.
2. Open the project folder in Android Studio or VS Code.
3. Run `flutter pub get` to install dependencies.
4. Start an Android emulator or connect a physical device.
5. Run `flutter run` to launch the application.
